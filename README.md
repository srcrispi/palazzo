# Palazzo

Sitio Roleplay con tema **full verde** + **Supabase** (datos e imágenes en la nube).

## Admin
Contraseña: `palazzo`

## Características
- Tema full verde
- Panel de administración
- Galería de fotos (Supabase Storage)
- Datos guardados en Supabase
- Responsive

## URLs
- https://palazzo-sage.vercel.app
- https://github.com/srcrispi/palazzo

## Stack
HTML/CSS/JS + Supabase (tablas `palazzo_data`, `photos` + bucket `photos`)
